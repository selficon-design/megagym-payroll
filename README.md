# MEGA GYM · Δηλώσεις μισθοδοσίας & Καρτέλα εργαζομένου (έκδοση 2.1)

Εφαρμογή για τις μηνιαίες δηλώσεις μισθοδοσίας εργαζομένων. Ανοίγει σε υπολογιστή, κινητό και tablet και εγκαθίσταται σαν εφαρμογή (PWA).

## Τι κάνει
- **Επισκόπηση μήνα**: υπογεγραμμένες, προς υπογραφή και χωρίς δήλωση, με πρόοδο ανά κατάστημα και ποσά ανά εταιρεία.
- **Εκκρεμότητες**: ποιος λείπει, με φίλτρα και εξαγωγή σε Excel.
- **Προετοιμασία δηλώσεων**: μαζικά, είτε στην οθόνη είτε από Excel (το πρότυπο έρχεται έτοιμο με τους εργαζομένους).
- **Tablet καταστήματος**: πλήρης οθόνη μόνο για υπογραφές. Η έξοδος γίνεται με τον κωδικό του manager.
- **Δηλώσεις**: αρχείο με την υπογραφή, PDF, ακύρωση με αιτιολογία (μόνο η ιδιοκτήτρια) και μηνιαίο backup σε ZIP.
- **Εργαζόμενοι**: μητρώο με κοινούς κωδικούς και εισαγωγή/εξαγωγή Excel (συμβατό με το παλιό πρότυπο).
- **Βοηθός AI**: ερωτήσεις σε απλά ελληνικά. Απαντά μόνο με όσα επιτρέπονται στον ρόλο του χρήστη.
- **Ιστορικό ενεργειών**: καταγράφεται αυτόματα από τη βάση και δεν αλλάζει.
- **Χρήστες & ρόλοι**: Γενική Διευθύντρια, HR, Manager (μόνο το κατάστημά του), Εκπαιδευτής (μόνο αξιολογήσεις στο πεδίο του). Οι εργαζόμενοι δεν χρειάζονται λογαριασμό.

### Νέο στην 2.1 — Ενιαία καρτέλα εργαζομένου
- **Καρτέλα εργαζομένου**: ίδιος κωδικός σε όλες τις ενότητες, ιστορικό καταστήματος/ειδικότητας.
- **Αιτήματα & Αναφορές Προσωπικού**: αίτημα εργαζομένου μέσω manager (καταγραφή ή απομονωμένη φόρμα εργαζομένου), αναφορές manager,
  διαφορετική ροή έγκρισης ανά κατηγορία, αναθεώρηση από ΓΔ, πλήρες ιστορικό.
- **Πρότυπα κειμένων** με εκδόσεις (Ρυθμίσεις).
- **Ημερήσια στατιστικά** Ρεσεψιόν / Επίβλεψης / Exclusive και αναφορές διαστήματος.
- **Αξιολογήσεις**: ερωτηματολόγια από Excel, διάστημα διαθεσιμότητας, συμπλήρωση από τον ίδιο τον εργαζόμενο, βαθμολόγηση στον server.

Οδηγίες χρήσης ανά ρόλο, έλεγχοι και εκκρεμότητες: **[docs/ΟΔΗΓΟΣ_ΚΑΡΤΕΛΑΣ_ΕΡΓΑΖΟΜΕΝΟΥ.md](docs/ΟΔΗΓΟΣ_ΚΑΡΤΕΛΑΣ_ΕΡΓΑΖΟΜΕΝΟΥ.md)**

## Ασφάλεια
- Όλοι οι έλεγχοι δικαιωμάτων γίνονται **μέσα στη βάση** (Row Level Security + συναρτήσεις), όχι μόνο στην οθόνη.
- Μία δήλωση ανά εργαζόμενο και μήνα. Η υπογεγραμμένη δήλωση δεν αλλάζει και δεν διαγράφεται· μόνο ακυρώνεται με αιτιολογία.
- Το κείμενο της δήλωσης το γράφει η βάση τη στιγμή της υπογραφής.
- Οι δημόσιες εγγραφές είναι κλειστές: λογαριασμούς φτιάχνει μόνο η ιδιοκτήτρια.
- Οι εικόνες υπογραφών δεν στέλνονται ποτέ στον Βοηθό AI.

## Δομή
```
web/                      η εφαρμογή (HTML/CSS/JS, χωρίς build)
supabase/migrations/      η βάση: πίνακες, ρόλοι, ασφάλεια, συναρτήσεις
supabase/functions/       λειτουργίες server: admin-users (λογαριασμοί), ask (Βοηθός AI)
tests/                    έλεγχοι βάσης ανά ρόλο και τύπων στατιστικών (τρέχουν πριν από κάθε deploy)
tests/e2e/                έλεγχοι σε πρόγραμμα περιήγησης (μόνο τοπικά)
docs/                     οδηγός επέκτασης
.github/workflows/        αυτόματο deploy
```

## Αυτόματο deploy
Κάθε αλλαγή στο `main` περνά αυτόματα από τους ελέγχους, ενημερώνει τη βάση και τις λειτουργίες και δημοσιεύει την εφαρμογή.

Secrets (GitHub → Settings → Secrets and variables → Actions):

| Secret | Από πού |
|---|---|
| `SUPABASE_ACCESS_TOKEN` | supabase.com → Account → Access Tokens → Generate |
| `SUPABASE_PROJECT_REF` | ο κωδικός του project (το κομμάτι πριν από `.supabase.co`) |
| `SUPABASE_DB_PASSWORD` | ο κωδικός βάσης που ορίστηκε στη δημιουργία του project |
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys (για τον Βοηθό AI) |
| `OWNER_EMAIL` | το email της ιδιοκτήτριας |
| `OWNER_PASSWORD` | κωδικός πρώτης εισόδου της ιδιοκτήτριας (τουλάχιστον 8 χαρακτήρες) |
| `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` | προαιρετικά, αν θέλετε φιλοξενία στο Cloudflare αντί για GitHub Pages |

Προαιρετικές μεταβλητές (Variables): `OWNER_NAME`, `AI_MODEL` (προεπιλογή `claude-haiku-5-5`).

Για GitHub Pages: Settings → Pages → Source: **GitHub Actions**.

## Τοπική δοκιμή
Ανοίξτε το `web/` με οποιονδήποτε απλό server (π.χ. `python3 -m http.server -d web`). Χωρίς ρυθμίσεις στο `web/config.js`, η εφαρμογή ανοίγει σε **λειτουργία επίδειξης** με φανταστικά δεδομένα.

Έλεγχοι βάσης: `PGHOST=... PGUSER=... ./tests/run.sh` (χρειάζεται PostgreSQL 16). Τύποι στατιστικών: `node --test tests/js/stats-calc.test.mjs`.
Οι νέες ενότητες (αιτήματα, στατιστικά, αξιολογήσεις) χρειάζονται βάση· στη λειτουργία επίδειξης δεν εμφανίζονται.

## Μεταφορά από την παλιά εφαρμογή
Οι εργαζόμενοι περνούν με το ίδιο Excel (φύλλο «Εργαζόμενοι», ίδιες στήλες): Εργαζόμενοι → Εισαγωγή Excel. Οι παλιές υπογεγραμμένες δηλώσεις μένουν στα PDF του backup της παλιάς εφαρμογής.
